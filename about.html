Over

Hoi, ik ben Dylan.

Systems-minded developer. Ik houd van low-level development, game development en van dingen opleveren die werken.

Ik ben student software developer bij het Talland college in Alkmaar. Ik volg het keuzevak game development en werk daarin met Unreal Engine. In 2025–2026 liep ik stage bij Randstad, waar mijn proof of concept voor een JSON-vergelijkingstool in Java uitgroeide tot een onderdeel van hun interne systeem. Ik heb ervaring met zowel frontend als backend, maar ik vind low-level system development het leukst. Ik ben altijd open om nieuwe talen en frameworks te leren.

Ik werk graag aan problemen waar beperkingen ertoe doen: weinig geheugen, trage opslag, een oude processor. Ik geef veel om prestaties en om code die later makkelijk op te pakken is.

Het meeste van mijn werk is gericht op het maken van low-level apps en utilities: van core-utilities naar interpreters en graphics programming op gelimiteerde hardware. Als ik niet aan het bouwen ben, ben ik meestal aan het testen of werk ik aan een zijproject.

Hoe ik werk

  • Begin bij de gebruiker — als ik iets maak dan begin ik bij de benodigdheden van de gebruiker.
  • Houd het leesbaar — de volgende die het bestand opent, ben ik waarschijnlijk zelf.
  • Meet, gok niet — prestaties zijn een functie, geen bijzaak. Goede performance is bij mij een must.
